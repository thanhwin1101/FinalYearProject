1. Preflight: `if (-not (Test-Path $MosquittoBin)) { Write-Error "mosquitto_passwd not found at $MosquittoBin. Install Mosquitto or pass -MosquittoBin."; exit 10 }`. Same check for `Get-Command pwsh` feature fallbacks is not needed.

2.5. Preflight: invoke `Test-MosquittoAuthEnforced -ConfigPath $MosquittoConf` (new helper function inside this script — see below). 3. Call `$newPass = & (Join-Path $PSScriptRoot 'generate-secure-password.ps1') -Length 32`. Validate length == 32 and charset regex `^[A-Za-z0-9\-_]{32}$`; otherwise exit 12.

5. Mutate Mosquitto file: `& $MosquittoBin -b $PasswordFile $Username $newPass`. Check `$LASTEXITCODE`; if non-zero, restore from `$bak` (`Copy-Item $bak $PasswordFile -Force`) and exit 13.

Helper function (define near top of script, before the Param block's usage):
```powershell
function Test-MosquittoAuthEnforced {
    param([Parameter(Mandatory=$true)][string]$ConfigPath)
    # Gate rotation on the broker actually enforcing auth. Without this, rotation
    # is ceremonial — the broker still allows anonymous clients, so stealing
    # the new password gains an attacker nothing they didn't already have.
    if (-not (Test-Path $ConfigPath)) {
        Write-Error @"
Mosquitto config not found at $ConfigPath.
Cannot confirm that authentication is enforced on this broker.
Pass -MosquittoConf <path> pointing to the broker's mosquitto.conf.
Rotation aborted to prevent ceremonial rotation on an open broker.
"@
        return $false
    }
    $conf = Get-Content $ConfigPath -Raw
    # Must have BOTH a password_file directive AND allow_anonymous false.
    # Comments (# ...) must be stripped first.
    $active = ($conf -split "`n") | Where-Object { $_ -notmatch '^\s*#' } | Out-String
    $hasPwdFile = $active -match '(?im)^\s*password_file\s+\S+'
    $anonDenied = $active -match '(?im)^\s*allow_anonymous\s+false\b'
    if (-not ($hasPwdFile -and $anonDenied)) {
        Write-Error @"
Broker auth NOT enforced in $ConfigPath.
Required (both lines, active/uncommented):
    password_file <path>
    allow_anonymous false

Found password_file directive : $hasPwdFile
Found allow_anonymous false   : $anonDenied

Rotating the password on an open broker is ceremonial — anonymous clients
still connect. Fix the broker config first, restart mosquitto, then re-run.
"@
        return $false
    }
    return $true
}
```

| rotate-mosquitto-password.ps1 stdout → operator memory | Password leaves the script exactly once via console; operator must capture it to password manager, not logs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01-01 | Information Disclosure | `rotate-mosquitto-password.ps1` prints password to console | mitigate | Password printed once, clearly marked; runbook step 4 mandates immediate capture to password manager. Script never writes it to a log file. |
| T-01-01-02 | Tampering | `.bak-<timestamp>` file left on broker host indefinitely | accept | Broker host is a controlled server (physical/RDP restricted). Cleanup scheduled in quarterly rotation itself (add new .bak, archive older than 180 days). Documented in runbook §6. |
| T-01-01-03 | Denial of Service | `mosquitto_passwd` failure mid-write corrupts `passwords.conf`, locks out all users | mitigate | Backup taken BEFORE write (step 4 of script); rollback on any mosquitto_passwd non-zero exit (step 5). Verified by acceptance criterion "rolled back automatically". |
| T-01-01-04 | Repudiation | Who rotated what and when | mitigate | Runbook §9 Change log table; admin adds a row on every rotation with date/name/ticket. |
