### pre-commit framework hook structure (.pre-commit-config.yaml schema)
Standard YAML. trufflehog v3 official hook:
```yaml
repos:
  - repo: https://github.com/trufflesecurity/trufflehog
    rev: v3.90.2   # pin a release tag — use a recent stable; plan-time suggestion v3.90.2 (verify during execution via `git ls-remote --tags https://github.com/trufflesecurity/trufflehog | tail -20`)
    hooks:
      - id: trufflehog
        name: trufflehog v3 — secret scan
        entry: trufflehog filesystem --fail --no-update .
        language: golang
        types: [text]
```
Note: the official trufflehog pre-commit hook is simple; executing `trufflehog filesystem --fail --no-update` over the repo is the supported invocation. Executor MUST verify rev tag against current releases and use the latest v3.x tag.

useDefault = true   # keep built-in ruleset (aws keys, github tokens, etc.)

regex = '''(?i)mqtt_?(pass|password)\s*[:=]\s*["']?([A-Za-z0-9_\-]{4,})["']?'''

File `.git/hooks/pre-push` (bash on *nix, but git runs it via MSYS bash on Windows Git for Windows). Contract:
- stdin: lines "local_ref local_sha remote_ref remote_sha"
- exit 0 → push proceeds; non-zero → push blocked.

We ship a template at `scripts/hooks/pre-push` (tracked); user copies to `.git/hooks/pre-push` (not tracked) during dev setup. Content calls PowerShell:
```bash

```

**scripts/hooks/pre-push** (bash, cross-platform via Git's bash):

```bash
#!/usr/bin/env bash
# Git pre-push hook — invokes scripts/scan-secrets.ps1 to block pushes containing secrets.
# Installation: Copy-Item scripts/hooks/pre-push .git/hooks/pre-push (Windows)
#               chmod +x .git/hooks/pre-push (if on WSL/bash after copy)
# See docs/DEV-SETUP.md § Secret scanning.

set -e

# On Windows Git Bash, pwsh is the canonical PowerShell; on *nix it's also pwsh if installed.
if ! command -v pwsh >/dev/null 2>&1; then
    echo "pre-push hook: pwsh not found. Install PowerShell 7+ and try again." >&2
    echo "  winget install Microsoft.PowerShell" >&2
    exit 60
fi

REPO_ROOT="$(git rev-parse --show-toplevel)"
exec pwsh -NoProfile -File "$REPO_ROOT/scripts/scan-secrets.ps1"
```
